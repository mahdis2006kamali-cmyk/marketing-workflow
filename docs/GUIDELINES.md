# 📋 راهنمای کار Marketing Workflow

## 🎯 اصول اساسی

### 1. روند کار
```
ایده → تحلیل → اجرا → ارزیابی
```

### 2. قوانین کار
- **یک Issue برای هر مرحله**: ایده، تحلیل، اجرا جداگانه
- **Labels واضح**: برای دسته‌بندی و ردگیری
- **محدودیت زمانی**: هر مرحله یک زمان‌بندی مشخص دارد
- **گزارش‌دهی منظم**: هفتگی و ماهانه

## 📝 مراحل تفصیلی

### مرحله 1️⃣: ایده (IDEA)
**زمان**: 1-2 روز
**معیار تکمیل**:
- ✅ ایده کاملا واضح
- ✅ هدف تعریف شده
- ✅ مخاطب مشخص

### مرحله 2️⃣: تحلیل (ANALYSIS)
**زمان**: 3-5 روز
**معیار تکمیل**:
- ✅ تحلیل کامل انجام شد
- ✅ منابع برآورد شد
- ✅ KPI مشخص شد

### مرحله 3️⃣: اجرا (EXECUTION)
**زمان**: متغیر (1 هفته تا 1 ماه)
**معیار تکمیل**:
- ✅ محتوا آماده شد
- ✅ کانال‌ها آماده شد
- ✅ ردگیری فعال است

### مرحله 4️⃣: ارزیابی (EVALUATION)
**زمان**: 2-3 روز
**معیار تکمیل**:
- ✅ داده‌ها جمع‌آوری شد
- ✅ تحلیل انجام شد
- ✅ گزارش نهایی نوشته شد

## 🏷️ استفاده از Labels

| Label | کاربرد |
|-------|--------|
| `idea` | ایده جدید |
| `analysis` | تحت تحلیل |
| `ready` | آماده اجرا |
| `in-progress` | در حال اجرا |
| `completed` | تکمیل شده |
| `urgent` | فوری |
| `review` | نیازمند بررسی |

## 💡 بهترین روش‌ها

✅ **DO:**
- عنوان واضح و مختصر برای Issues
- توضیح کامل اما مختصر
- استفاده از قالب‌های موجود
- ارتباط دهی به Issues مرتبط
- به‌روزرسانی روزانه وضعیت

❌ **DON'T:**
- عنوان بسیار طولانی
- توضیح غیرواضح
- عدم استفاده از قالب
- اضافه کردن اطلاعات غیر ضروری
- فراموش کردن Issues
